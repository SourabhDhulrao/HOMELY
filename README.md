# HOMELY — Thoughtful Finds for Beautiful Everyday Living

An editorial home discovery and affiliate curation platform tailored for modern Indian living. Built with the warmth of Scandinavian minimalism and the visual sophistication of a boutique interior magazine.

---

## ✨ Philosophy & Highlights

- **Editorial Discovery**: Kinfolk-inspired lifestyle magazine aesthetic over generic e-commerce templates.
- **Exact Amazon India Matching**: 1-to-1 matching between curated recommendations and live Amazon India products with affiliate tracking.
- **Manual Product Control**: Complete admin studio to upload actual product photos, verify live destinations, and publish bespoke editorial takes.
- **Pinterest-First Growth**: Integrated Pin-creation tools and viral discovery cards.
- **Warm Editorial Palette**: 60/30/10 balance of Warm Ivory (`#F6F2E9`), Muted Sage (`#879681`), and Burnt Terracotta (`#C4775A`).

---

## 🛠️ Stack

- **Framework**: Next.js 14+ (App Router, Server Components)
- **Styling**: Tailwind CSS, Framer Motion
- **Icons**: Lucide React
- **Storage & Database**: Supabase (PostgreSQL & Storage) with zero-config local fallback
- **Typography**: Playfair Display, DM Sans, Cormorant Garamond

---

## 🚀 Quick Start

1. **Clone & Install**:
   ```bash
   git clone https://github.com/SourabhDhulrao/HOMELY.git
   cd HOMELY
   npm install
   ```

2. **Run Locally**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) for the storefront and [http://localhost:3000/admin](http://localhost:3000/admin) for the Admin Studio (passkey: `homely2025`).
